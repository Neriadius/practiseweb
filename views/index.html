REST API Practice Tasks 11-13

Available Endpoints:

GET /

Root endpoint - Welcome message

GET /version

Task 12: Version information

GET /health

Task 12: Health check endpoint

Items API (Task 13):

GET /api/items

Get all items

POST /api/items

Create new item (use POSTMAN for testing)

PUT /api/items/:id

Full update item (use POSTMAN)

PATCH /api/items/:id

Partial update item (use POSTMAN)

DELETE /api/items/:id

Delete item (use POSTMAN)

Instructions:

  1. Install dependencies: npm install
  2. Create .env file with MongoDB URI
  3. Run locally: npm run dev
  4. Test endpoints using buttons above or Postman
  5. Deploy to Heroku/Railway/Vercel
